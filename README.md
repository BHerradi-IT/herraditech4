# صفحة الويب لـ هرادي تيك

## نظرة عامة

هذه صفحة ويب احترافية لعرض خدمات **هرادي تيك**، تم تصميمها باستخدام HTML و CSS و JavaScript بألوان الأبيض والأخضر الفاتح.

## محتويات المشروع

المشروع يحتوي على ثلاثة ملفات رئيسية:

1. **index.html** - ملف HTML الرئيسي الذي يحتوي على هيكل الصفحة
2. **styles.css** - ملف CSS الذي يحتوي على تنسيقات الصفحة والألوان
3. **script.js** - ملف JavaScript الذي يضيف التفاعلية للصفحة

## الأقسام المتوفرة في الصفحة

الصفحة تحتوي على الأقسام التالية:

- **شريط التنقل**: يحتوي على روابط لجميع أقسام الصفحة
- **قسم البطل (Hero)**: عنوان رئيسي ووصف موجز للخدمات
- **قسم الخدمات**: يعرض الخدمات الخمس الرئيسية:
  - بيع الكتب
  - أداء الفواتير
  - التسجيل في المدارس
  - إرسال التعبئة
  - طلب الوثائق الإدارية
- **قسم نبذة عنا**: معلومات عن هرادي تيك
- **قسم آراء العملاء**: عرض آراء العملاء مع نموذج لإضافة اقتراحات
- **قسم الاتصال**: معلومات الاتصال ونموذج للتواصل
- **التذييل**: حقوق النشر

## كيفية استخدام الصفحة

### الطريقة الأولى: فتح الصفحة محليًا

1. قم بفك ضغط ملف `heradi_tech_website.zip`
2. افتح مجلد `heradi_tech_website`
3. انقر نقرًا مزدوجًا على ملف `index.html`
4. ستفتح الصفحة في متصفحك الافتراضي

### الطريقة الثانية: نشر الصفحة على الإنترنت

يمكنك رفع الملفات إلى أي خدمة استضافة مواقع مثل:

- **GitHub Pages** (مجاني)
- **Netlify** (مجاني)
- **Vercel** (مجاني)
- أي خدمة استضافة ويب تدعم HTML

#### خطوات النشر على GitHub Pages:

1. أنشئ حساب على [GitHub](https://github.com) إذا لم يكن لديك حساب
2. أنشئ مستودع جديد (Repository)
3. ارفع الملفات الثلاثة (index.html, styles.css, script.js) إلى المستودع
4. اذهب إلى Settings > Pages
5. اختر المصدر (Source) كـ "main branch"
6. احفظ التغييرات وستحصل على رابط للصفحة

## الميزات

- **تصميم متجاوب**: تعمل الصفحة بشكل ممتاز على جميع الأجهزة (الحاسوب، الجهاز اللوحي، الهاتف المحمول)
- **ألوان مخصصة**: تستخدم الأبيض والأخضر الفاتح كما هو مطلوب
- **تفاعلية**: تحتوي على تأثيرات حركية عند التمرير والتنقل
- **نماذج وظيفية**: نماذج الاتصال والاقتراحات تفتح برنامج البريد الإلكتروني تلقائيًا
- **خطوط عربية جميلة**: تستخدم خط Cairo من Google Fonts

## التخصيص

يمكنك تخصيص الصفحة بسهولة:

### تغيير الألوان:

افتح ملف `styles.css` وعدّل المتغيرات في بداية الملف:

```css
:root {
    --primary-color: #7ed957;  /* اللون الأخضر الفاتح */
    --primary-dark: #5fb83d;   /* اللون الأخضر الداكن */
    --secondary-color: #ffffff; /* اللون الأبيض */
}
```

### تغيير المحتوى:

افتح ملف `index.html` وعدّل النصوص حسب رغبتك.

### إضافة صور:

يمكنك إضافة صور في مجلد `images` وربطها في ملف HTML.
